# Huron Industry Skills and Leading Practices

This folder holds Huron-authored, industry-specific leading practices and
configuration guidance for Oracle Fusion Cloud implementations. It is
separate from Oracle's own `pillars/`, `core/`, `shared/`, `governance/`,
`schemas/`, and `knowledge/` folders, which are Oracle-owned and updated by
Oracle's releases.

## Structure

```text
industries/
  <industry-name>/
    <pillar>/<offering-or-topic>/leading-practice.md
```

Each industry folder may contain narrative guidance (Markdown) and reference
configuration workbooks (e.g., `.xlsx`) that an implementation team or AI
agent should consult when working in that industry context.

## Industries

- `healthcare/`
- `higher-education/`
- `public-sector/`
- `commercial/`
